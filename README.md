# 달러선물 전망

달러/원(USD/KRW)을 매일 보기 위한 한 화면 대시보드입니다. 지표 종합 점수, 오늘 예상 밴드, 피벗·이평·고저 가격대, 직전 16시 이후 주변 시장 변화와 그로 본 예상 변동, 경제지표 일정, 환율 뉴스를 보여 줍니다.

> 공개 시세로 계산한 참고 지표입니다. 투자 권유가 아니며, 점수의 과거 적중률을 화면에 그대로 보여 줍니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:8787 (화면 코드를 묶은 뒤 Worker를 띄웁니다)
npm test           # 지표·시간 정렬 단위 테스트
npm run typecheck
```

## 배포 (Cloudflare Workers, 고정 주소)

```bash
npx wrangler login     # 처음 한 번, 브라우저에서 Cloudflare 계정 승인
npm run deploy         # → https://dollar-outlook.<내 서브도메인>.workers.dev
```

- 주소는 Worker 이름(`wrangler.jsonc`의 `name`)으로 정해지고, 다시 배포해도 바뀌지 않습니다.
- 내 도메인을 쓰려면 Cloudflare 대시보드 → Workers → dollar-outlook → Settings → Domains & Routes에서 추가합니다.
- 비밀값·DB가 필요 없습니다. 무료 플랜으로 충분합니다(Worker는 시세를 해석하지 않고 중계만 하므로 CPU를 거의 쓰지 않습니다).
- 혼자만 보고 싶다면 Cloudflare Zero Trust의 Access로 이메일 로그인을 걸 수 있습니다.

## 구조

| 위치 | 역할 |
|---|---|
| `src/worker/index.ts` | `/api/market?p=hist\|live`(Yahoo 시세 묶음), `/api/calendar`, `/api/news`. 메모리 캐시 + 엣지 캐시, 실패 시 마지막 값 사용 |
| `src/worker/calendar.ts` | Forex Factory 주간 일정에서 미국·중국(중간 이상), 일본·유로존(높음)만 골라 한글 제목을 붙임 |
| `src/worker/news.ts` | Google 뉴스 RSS '원달러 환율' |
| `src/lib/market.ts` | Yahoo 응답 → KST 시계열, 16:00 기준 값(`asOf`), 서울 세션 일봉 |
| `src/lib/indicators.ts` | SMA·EMA·RSI·MACD·볼린저·ATR·피벗·상관·릿지 회귀 |
| `src/lib/outlook.ts` | 요인 점수, 백테스트, 예상 밴드, 가격대, 요약 문장 |
| `src/app/main.ts` | 화면 그리기(브라우저에서 계산). `npm run build`가 `public/app.js`로 묶음 |
| `public/` | `index.html`, `style.css`, 차트 라이브러리(lightweight-charts 4.2.0, Apache-2.0) |

## 계산 방법

**시간 맞추기.** Yahoo의 FX 일봉 종가는 찍히는 시각이 들쭉날쭉합니다(위안은 며칠 같은 값이 반복되기도 함). 그래서 1년치 1시간봉과 5일치 15분봉으로 모든 종목을 **그날 16:00 KST에 알 수 있던 마지막 가격**으로 다시 맞춥니다(달러선물 주간장 마감 15:45 직후). 달러/원 일봉은 09:00~16:00 KST 서울 세션으로 만들고, 밤사이 움직임은 다음 봉 시가와의 간격으로 남습니다.

**종합 점수(-100~+100, +는 달러/원 상승 쪽).** 각 요인을 -1~+1로 재고 비중을 곱해 더합니다.

| 요인 | 비중 | 재는 방법 |
|---|---|---|
| 추세 | 20% | 현재가와 20일선, 5/20일선, 20/60일선, 20일선 기울기 |
| 모멘텀 | 15% | MACD 히스토그램 ÷ ATR |
| 과열·침체(역추세) | 10% | RSI 70↑/30↓, 볼린저 %B 밴드 이탈 |
| 글로벌 달러 | 20% | 달러인덱스·달러/위안 5일 변화의 표준점수 |
| 위험 회피 | 15% | 나스닥 선물·코스피 하락, VIX 상승의 5일 표준점수 |
| 미 금리 | 5% | 미 10년물 5일 변화의 표준점수 |
| 직전 16시 이후 변동 | 15% | 직전 16시 대비 현재 변화 ÷ ATR |

±20 이상이면 '상승/하락 우위'로 부릅니다. 화면에는 같은 규칙(마감 이후 요인 제외)을 지난 1년에 적용했을 때 다음 날 방향 적중률과, 매일 한 방향으로만 찍었을 때의 비율을 함께 보여 줍니다. 처음 만들었을 때(2026-10-21) 적중률은 52%, 한 방향 기준선은 55%였습니다. 점수는 방향을 맞히는 신호라기보다 지금 분위기를 요약하는 용도로 보세요.

**예상 밴드.** 오늘 09시 시가(장 전에는 현재가) ± 세션 ATR(14)의 절반. 세션 중에는 이미 찍은 고가·저가를 포함합니다. 피벗은 직전 세션 고가·저가·종가로 계산합니다.

**직전 16시 이후 예상 변동.** 최근 120거래일의 16시 기준 일간 변화로 달러/원을 달러인덱스·위안·나스닥 선물·미 10년물에 릿지 회귀하고, 그 민감도에 직전 16시 이후 변화를 곱합니다. 실제 변동과의 차이는 원화만의 강약을 뜻합니다.

## 주의

- 시세는 Yahoo Finance 비공식 API입니다. 지연·누락이 있을 수 있고, 응답 형식이 바뀌면 고쳐야 합니다.
- 화면의 달러/원은 현물 시세입니다. 달러선물 가격은 여기에 스왑포인트만큼 차이가 납니다.
- 처음 열 때 1년치 시간봉(압축 전 약 5MB)을 받습니다. 브라우저가 30분간 다시 쓰고, 이후에는 1분마다 최근 5일치만 새로 받습니다.
